### RPLab
## introduction
RPLab is a graphical user interface to interact with, and run custom DSP fpga configurations on Red Pitaya development boards. currently RPLab is only available on windows PC.

## Build
**currently RPLab is only buildable on windows!**

RPLab is build on the [LabCore / Physica](https://github.com/ThijsJansen02/Physica/tree/dev-RPLab) framework and adds this as a sub module. Currently this software requires a [VulkanSDK](https://vulkan.lunarg.com/sdk/home) installation on your computer. When this SDK is installed the the premake buildconfig automatically figures out where it is located.
